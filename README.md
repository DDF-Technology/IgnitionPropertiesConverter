# IgnitionPropertiesConverter

Utility desktop per convertire file di localizzazione `.properties` in un foglio Excel e
ricreare i file `.properties` dalle colonne linguistiche del foglio.

## Avvio dal sorgente

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

L'eseguibile storico in `dist` è conservato localmente ma escluso dal repository.
