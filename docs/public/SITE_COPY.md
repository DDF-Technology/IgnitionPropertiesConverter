# Testi proposti per il sito

## Portfolio

### Ignition Properties Converter

Utility desktop gratuita per semplificare la revisione delle localizzazioni nei progetti SCADA Ignition. Converte più file `.properties` in un unico foglio Excel, organizzando chiavi e lingue in forma tabellare, e rigenera successivamente i file di lingua.

Il progetto gestisce escape, Unicode e continuazioni, rileva chiavi o lingue duplicate, protegge i valori testuali dall'interpretazione come formule e scrive gli output in modo atomico.

**Python · Tkinter · pandas · openpyxl · MIT**
