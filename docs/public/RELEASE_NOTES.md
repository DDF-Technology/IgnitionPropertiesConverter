# Note di versione

## 1.0.0-rc2

- Distribuzione completa e gratuita sotto licenza MIT.
- Conversione multipla `.properties` → Excel e rigenerazione Excel → `.properties`.
- Parser UTF-8 con escape, Unicode, continuazioni e rilevamento duplicati.
- Scrittura atomica dei file di uscita.
- Protezione dei valori che iniziano con `=` e rifiuto delle formule Excel.
- Esempi sintetici, test automatici, checksum e licenze di terze parti.
- Interfaccia ridisegnata e verificata con scaling DPI Windows.

Questa versione è pubblicata come pre-release non firmata. Windows può mostrare un avviso di
sicurezza: verificare il checksum SHA-256 prima dell'avvio. La firma Authenticode resta prevista
per eventuali release stabili future.
