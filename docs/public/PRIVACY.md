# Privacy

Ignition Properties Converter opera interamente in locale. Non usa rete, telemetria, account o servizi cloud e non raccoglie dati personali. Legge esclusivamente i file scelti dall'utente e scrive soltanto nelle destinazioni selezionate.

Il contenuto dei file elaborati resta sul dispositivo. Il sistema operativo e gli strumenti di sicurezza installati possono produrre autonomamente log secondo le rispettive configurazioni.
